# BEAGLE

Code and tools from the BEAGLE project (EU Horizon Europe; Biodiversity methods for advanced monitoring at large scales), 
which is using new technology to boost biodiversity monitoring across terrestrial, freshwater, and marine environments 
in the EU and associated countries. Specifically, the project uses sensors, environmental DNA (eDNA) and AI, 
as well as citizen science to collect large-scale and high-quality biodiversity data. 
The collected data will be transformed into standardised indicators that will help the EU and the world to achieve its biodiversity targets.
